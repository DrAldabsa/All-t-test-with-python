# 🧪 الاختبارات الإحصائية المدعومة

## 1. اختبار T لعينة واحدة

### One-Sample t-test

يستخدم هذا الاختبار لمقارنة **متوسط عينة واحدة** مع متوسط مرجعي أو متوسط مجتمع محدد.

على سبيل المثال، إذا كانت لدينا بيانات إنتاجية القمح ونريد معرفة ما إذا كان متوسط الإنتاج يختلف عن قيمة مرجعية مقدارها `4 طن/دونم`.

يتم اختبار الفرضيات:

```text
H₀: μ = μ₀

H₁: μ ≠ μ₀
```

ويمكن أيضاً استخدام الفرضية البديلة:

```text
H₁: μ > μ₀
```

أو:

```text
H₁: μ < μ₀
```

### المدخلات المطلوبة

* مسار ملف CSV.
* اسم العمود.
* المتوسط المرجعي `population_mean`.
* مستوى الدلالة `alpha`.
* مستوى الثقة.
* نوع الفرضية البديلة.
* اختيار إزالة القيم الشاذة من عدمه.

---

# 2. اختبار T لعينتين مستقلتين

### Independent Samples t-test

يستخدم هذا الاختبار لمقارنة متوسط مجموعتين مستقلتين.

مثلاً:

```text
المجموعة الأولى → صنف قمح A

المجموعة الثانية → صنف قمح B
```

ويتيح البرنامج اختيار نوع اختبار التباين.

### Student's t-test

يستخدم عندما نفترض تساوي التباينات بين المجموعتين:

```text
Equal Variances
```

ويستخدم البرنامج:

```python
stats.ttest_ind(
    group1_clean,
    group2_clean,
    equal_var=True
)
```

### Welch's t-test

يستخدم عندما لا نفترض تساوي التباينات:

```text
Unequal Variances
```

ويستخدم البرنامج:

```python
stats.ttest_ind(
    group1_clean,
    group2_clean,
    equal_var=False
)
```

وهذا الخيار موجود بشكل مباشر في الكود من خلال `variance_test`.

---

# 3. اختبار T للعينات المرتبطة

### Paired Samples t-test

يستخدم هذا الاختبار عندما تكون هناك قياسات مرتبطة، مثل:

```text
قبل المعاملة  ↔  بعد المعاملة
```

أو:

```text
نفس النباتات قبل المعاملة
          ↓
نفس النباتات بعد المعاملة
```

في هذه الحالة لا يتعامل البرنامج مع القياسين على أنهما مجموعتان مستقلتان.

بل يقوم أولاً بحساب الفرق بين كل زوج:

```python
differences = group1_p - group2_p
```

ثم يتم إجراء التحليل على هذه الفروق.

ويتم تنفيذ الاختبار باستخدام:

```python
stats.ttest_rel(
    group1_clean,
    group2_clean
)
```

# 📈 اكتشاف القيم الشاذة

يستخدم المشروع طريقة:

## Interquartile Range — IQR

يتم حساب الربع الأول:

```python
Q1 = np.percentile(values, 25)
```

والربع الثالث:

```python
Q3 = np.percentile(values, 75)
```

ثم:

```text
IQR = Q3 − Q1
```

وتحسب الحدود:

```text
Lower Bound = Q1 − 1.5 × IQR

Upper Bound = Q3 + 1.5 × IQR
```

وأي قيمة تقع خارج هذه الحدود تعتبر قيمة شاذة وفق معيار IQR المستخدم في البرنامج.

# 📐 حجم التأثير Cohen's d

لا يعتمد البرنامج على `p-value` فقط.

بل يقوم أيضاً بحساب:

## Cohen's d

والهدف هو معرفة **حجم الفرق عملياً** وليس فقط معرفة ما إذا كان الفرق ذا دلالة إحصائية.

ويتم تصنيف حجم التأثير كالتالي:

| |Cohen's d| | التفسير |
|---:|---|
| `< 0.20` | ضئيل جداً |
| `0.20 – < 0.50` | صغير |
| `0.50 – < 0.80` | متوسط |
| `≥ 0.80` | كبير |

ويطبق البرنامج هذا التصنيف على الاختبارات المختلفة.

# 📌 اتخاذ القرار الإحصائي

بعد الحصول على `p-value`، تتم مقارنتها بمستوى الدلالة `alpha`.

الافتراضي:

```text
α = 0.05
```

إذا:

```text
p-value < α
```

فإن البرنامج يعطي القرار:

```text
Reject H0
Statistically significant
```

أما إذا:

```text
p-value ≥ α
```

فيكون القرار:

```text
Fail to reject H0
Not statistically significant
```

وهذا القرار موجود في فروع الاختبارات المختلفة في الكود.

# ⚠️ ملاحظات إحصائية مهمة

هذا البرنامج يقوم بتنفيذ العمليات الحسابية والإحصائية، ولكنه **لا يستطيع أن يقرر نيابةً عن الباحث ما إذا كان اختبار T مناسباً لتصميم التجربة**.

لذلك يجب على الباحث التأكد من طبيعة البيانات وتصميم التجربة قبل اختيار الاختبار.

على سبيل المثال:

* يجب أن تكون بيانات **Independent t-test** مستقلة بين المجموعتين.
* يجب أن تكون بيانات **Paired t-test** مرتبطة فعلياً.
* يجب أن يكون المتوسط المرجعي في **One-Sample t-test** ذا معنى علمي.
* ينبغي عدم حذف القيم الشاذة لمجرد أنها شاذة إحصائياً دون مبرر علمي.
* لا ينبغي الاعتماد على `p-value` وحدها.
* من الأفضل تفسير `p-value` مع **Confidence Interval** و **Effect Size**.
* الدلالة الإحصائية لا تعني بالضرورة وجود أهمية عملية أو علمية كبيرة.
